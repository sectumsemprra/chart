Novel Training Methodologies to Enhance Chart-RVR Beyond NSR
Chart-RVR's 84.56% ChartQA and 53.36% EvoChart scores can be substantially improved by integrating
recent advances in reinforcement learning, reasoning architectures, and inference strategies. This report
identifies 18+ validated techniques from 2024-2025 research that synergize with GRPO-based training and
NSR. The highest-impact approaches—DAPO's dynamic sampling, Selective Sample Replay (SSR), and
Program-of-Thoughts reasoning—can each deliver 3-8% accuracy gains with modest implementation effort,
while the full stack of recommended techniques could push EvoChart OOD performance above 70%.

R3V (Reflection on CoT Rationales) enables self-improvement through iterative refinement. The model
bootstraps positive and negative solution pairs, then trains with self-refine and self-select losses. The self-refine
signal teaches correction of flawed rationales; self-select teaches choosing correct answers by comparing
candidate reasoning chains. This achieves 23-60% relative improvement over GPT-distilled baselines and
generalizes well to OOD benchmarks including ChartQA.
R3V integrates with GRPO by using self-generated solutions to create richer training data. Generate multiple
reasoning paths per chart question, filter by correctness, then use GRPO to rank chains within groups. Adding
"rationale quality" as a reward component (beyond just answer correctness) improves reasoning faithfulness.

vulnerability. Several techniques specifically target this.

Inference strategies deliver free accuracy gains
Self-consistency with majority voting is the lowest-hanging fruit. Sampling N=10-20 diverse reasoning paths
(temperature ~0.7) and selecting the most frequent answer improves accuracy by 3-5% with linear compute
cost. Confidence-Informed Self-Consistency (CISC, 2025) achieves comparable gains with 46-67% fewer
samples by weighting votes by model-generated confidence scores.

Recommended implementation roadmap
Phase 1: Immediate wins (Week 1-2)
Implement Dynamic Sampling from DAPO by filtering batches where all GRPO samples have identical
rewards. Add SSR by maintaining a replay buffer of high-advantage samples. These require minimal code
changes and deliver 3-8% combined improvement. Deploy self-consistency (N=10) at inference for +3-5%
additional gains with no training changes.
Phase 2: Reasoning enhancements (Week 3-4)
Integrate Program-of-Thoughts by adding code execution verification to GRPO rewards. Structure the
reasoning pipeline into explicit LLaVA-CoT stages with stage-specific reward components. Add Chain-of-Table
operations for table reasoning. Expected additional improvement: 5-10%.
Phase 3: OOD focus (Month 2)
Implement disentangled curriculum (text reasoning → visual grounding) to address visual forgetting. Deploy
TDA for training-free test-time adaptation on EvoChart. Generate synthetic training data using ChartGen
matching EvoChart's distribution. Expected OOD improvement: 10-15%.
Phase 4: Advanced techniques (Month 3+)
Train dedicated Critic-V model for chart reasoning verification with natural language feedback. Implement
MCTS-guided exploration for step-level reward generation. Add MoE routing for chart-type and question-type
specialization.

Conclusion
The most impactful immediate improvements combine DAPO's dynamic sampling (filtering uninformative
gradient signals), SSR (prioritizing high-value training samples), and Program-of-Thoughts (offloading
arithmetic to symbolic execution). These techniques are well-validated, straightforward to implement, and
synergize with existing GRPO training and planned NSR integration.
For OOD robustness—the critical gap between 84% in-domain and 53% out-of-domain—disentangled
curriculum learning (preventing visual forgetting), ChartGen synthetic augmentation (expanding
distribution coverage), and training-free test-time adaptation (inference-time robustness) represent the most
promising paths. The combination of these training and inference improvements could realistically push
EvoChart performance above 70% while maintaining or improving ChartQA accuracy.
The research landscape strongly favors dense, verifiable supervision (code execution, table operations, stage
level rewards) over end-to-end black-box training. Chart reasoning's inherent structure—explicit intermediate
representations in tables and calculations—makes it particularly amenable to these advances. Prioritizing
techniques that leverage this structure will yield the largest gains relative to implementation effort.
